# 🍅 Pomodoro Timer

A simple Pomodoro Timer built with Python and Tkinter, featuring a modern dark mode interface.

## ✨ Features

- ▶️ Start the timer
- ⏸️ Pause and resume
- 🔄 Reset the timer
- ⏱️ Choose between 5, 15, 25, and 45-minute sessions
- 🔔 Notification when the timer finishes
- 🌙 Dark mode with a purple accent
- 🖥️ Simple graphical user interface

## 🛠️ Built With

- Python
- Tkinter
- ttk
- Git and GitHub

## 🚀 How to Run

1. Install [Python](https://www.python.org/downloads/).
2. Clone this repository:

   ```bash
   git clone https://github.com/Mamaiedori96/pomodoro-timer.git
   ```

3. Open the project folder.
4. Run the application:

   ```bash
   python main.py
   ```
